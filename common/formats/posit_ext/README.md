# posit_ext — Posit32/64, Nf8, TaperedFp RTL Modules

Verilog-2005 RTL modules extending the Posit16 family in `common/formats/ai/`.  
Origin: `trios-trainer-igla/src/fake_quant.rs` (66 canonical `FormatKind` variants).

## Format Specifications

### Posit\<32,2\>  (ES=2, useed=16)

| Field    | Bits          | Notes                              |
|----------|---------------|------------------------------------|
| sign     | 31            | 0=positive, 1=negative             |
| regime   | 30..rlen      | unary run: k ones + 0 (k≥0), or \|k\| zeros + 1 (k<0) |
| exponent | 2 bits        | ES=2, value 0..3                   |
| mantissa | remaining     | implicit leading 1                 |

`scale = 4·k + exp`, `value = (−1)^sign · 16^k · 2^exp · (1 + mant_frac)`

Key constants:
- `0x40000000` = 1.0  (k=0, exp=0)
- `0x48000000` = 2.0  (k=0, exp=1)
- `0x38000000` = 0.5  (k=−1, exp=3)
- `0x44000000` = 1.5  (k=0, exp=0, mant[28]=1)
- `0x80000000` = NaR
- `0x00000000` = Zero

### Posit\<64,3\>  (ES=3, useed=256)

| Field    | Bits          | Notes                              |
|----------|---------------|------------------------------------|
| sign     | 63            |                                    |
| regime   | 62..rlen      | same unary encoding                |
| exponent | 3 bits        | ES=3, value 0..7                   |
| mantissa | remaining     | up to 56 bits                      |

`scale = 8·k + exp`, `value = (−1)^sign · 256^k · 2^exp · (1 + mant_frac)`

Key constants:
- `0x4000000000000000` = 1.0  (k=0, exp=0)
- `0x4400000000000000` = 2.0  (k=0, exp=1)
- `0x8000000000000000` = NaR
- `0x0000000000000000` = Zero

### NF8 — 8-bit NormalFloat

8-bit extension of QLoRA NF4 (Dettmers et al. 2023).  
Encoding: 256-entry LUT, values generated by CDF-inverse of N(0,1) at quantiles (i+0.5)/256, normalized to [−1, 1], stored as signed int16 (×32767).

- `nf8.v`: index → int16 decode (LUT) and float → nearest-index encode (sequential comparator)
- `nf8_dot4.v`: 4-lane dot-product, 4-bit accumulator per lane via 16-iter shift-add (R-SI-1 clean)

### TaperedFp

Parameterized by `WIDTH` (default 16, tested 8/16/32).  
ES=0 variant per Gustafson "Beating Floating Point at its Own Game" (2017) and Morris (1971).  
Regime directly encodes 2^k; no explicit exponent field.

Interface:
```
tapered_fp #(.WIDTH(16)) inst (
    .tfp_in, .dec_sign, .dec_k, .dec_mant, .dec_zero, .dec_nar,   // decode
    .enc_sign, .enc_k, .enc_mant, .enc_zero, .enc_nar, .tfp_out   // encode
);
```

## Compliance

- **Verilog-2005** (`-g2005`): all modules pass `iverilog -g2005`
- **`\`default_nettype none/wire`**: set at module boundaries
- **R-SI-1**: zero standalone `*` operators — mantissa multiplication via shift-add generate loops
  - posit32_mul: 30-iteration generate loop (30×30-bit)
  - posit64_mul: 32-iteration truncated generate loop (32×32-bit)
  - nf8_dot4: 16-iteration shift-add per lane

R-SI-1 verification:
```bash
! grep -nE '[^*/]\*[^*/=]' common/formats/posit_ext/*.v
```
